Calculadora de Salário Líquido

Aula prática A4 · Framework Python · mesmas regras do Flask

Informe os dados

INSS 8%, IR 15% se o bruto for maior que R$ 2.500,00 e R$ 200,00 por dependente.

Líquido = bruto − INSS − IR + (dependentes × 200).
IR só incide se o salário bruto for maior que R$ 2.500,00.
